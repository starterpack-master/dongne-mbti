# 🏘️ 우리 동네 MBTI

전국 가게 2,772,484곳의 업종 구성으로 행정동 3,558개의 "동네 MBTI"를 뽑아 주는 웹앱입니다.
홀로그램 포토카드 저장, 나랑 동네 궁합, 동네 배틀, 전국 동네 은하계 지도를 제공합니다.

**👉 [바로 해 보기](https://starterpack-master.github.io/dongne-mbti/)**

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm run build   # dist/index.html 단일 파일 생성 (코드·데이터가 파일 하나에 다 들어감)
npm run deploy  # 빌드 후 gh-pages 브랜치로 올려서 GitHub Pages에 배포
```

글꼴은 CDN에서 받아오므로 인터넷이 연결되어 있어야 디자인이 제대로 보입니다.

## 데이터 갱신 (분기마다)

1. 공공데이터포털에서 [소상공인시장진흥공단_상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do) zip 파일을 받습니다.
2. 행정동별 업종 개수를 집계합니다.
   ```bash
   python3 scripts/aggregate.py 상가정보.zip agg.json
   ```
3. MBTI 점수를 계산해 앱 데이터로 만듭니다 (`numpy` 필요).
   ```bash
   python3 scripts/build_data.py agg.json src/data/dongs.json
   ```
4. `npm run deploy`로 다시 빌드하고 배포합니다.

## 계산 방법

- 업종(소분류)마다 `이 동네 비율 ÷ 전국 비율`을 구합니다. 가게가 적은 동네는 전국 평균 쪽으로 보정합니다.
- 4개 축에 속한 업종들의 차이로 점수를 냅니다.
  - **E/I**: 술집·고깃집·노래방 vs 편의점·코인빨래방·반찬가게·스터디카페·배달
  - **S/N**: 시장·백반·철물점·목욕탕 vs 카페·빵집·소품샵·세계 음식
  - **T/F**: 오피스·자격증학원·헬스장 vs 뷰티·필라테스·동물병원·키즈
  - **J/P**: 학원·병원·약국 vs 놀거리·여행 숙소·레저
- 축끼리 겹치지 않도록 통계적으로 정리(ZCA whitening)해서 16개 유형이 고르게 나오게 했습니다.
- 재미로 보는 분석이며, 실제 주민 성격이나 살기 좋은 정도를 뜻하지 않습니다.
